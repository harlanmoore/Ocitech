What the decoder reads, and what it works out

A memory part number is a packed specification. Capacity, generation, module type, DRAM width and speed each sit at a fixed position. The decoder reads those positions using the manufacturer’s own numbering scheme, so it works on part numbers it has never seen, not only on a list of known ones.

Rank is the exception. Samsung, SK hynix and Micron’s DDR4 numbers do not print it, so the decoder works it out from capacity, die density and DRAM width and marks the result worked out. It agreed with the label on more than 100 modules from our buying catalog, but the label on the module has the final word. If the difference between 2Rx4 and 2Rx8 is new to you, read memory ranks explained.

Where to find the part number: it is on the white label on the module and starts with M (Samsung), HM (SK hynix), MT (Micron) or K (Kingston). The shorter line that reads like 32GB 2Rx4 PC4-2666V-RB2 is the specification line; you can paste that here too. Our guide to identifying server RAM shows real labels.

Samsung part numbers

Samsung module numbers start with M3 (full-size DIMM) or M4 (SODIMM). The next two digits give the module type, and the letter after them gives the generation: A for DDR4, R for DDR5. The speed is the last two characters after the dash and the letter C.

Example: M393A4K40CB2-CTD is a 32GB DDR4-2666 RDIMM, 2Rx4 module.

SK hynix part numbers

SK hynix uses two formats. DDR4 modules mostly use the older one, which starts HMA followed by the DRAM density and depth. All DDR5 modules, and some later DDR4 ones, use a 15-character format that starts HMC (DDR5) or HMA (DDR4) followed by G or T and a capacity code.

Micron part numbers

Micron DDR4 modules start MTA and DDR5 modules start MTC. Both open with the number of DRAM die on the module. The DDR4 scheme leaves rank and DRAM width to be worked out from that die count; the DDR5 scheme prints both.

Kingston part numbers

Kingston’s Server Premier (KSM) and ValueRAM (KVR) numbers are the most readable of the four: speed, module type, rank, DRAM width and capacity are all printed, and Server Premier adds the DRAM manufacturer and die revision. Kingston’s system-specific numbers (KTD-, KTH-, KTL-) are shorter and name the server family the module was built for.

Example: KSM56R46BD4PMI-64HAI is a 64GB DDR5-5600 RDIMM, 2Rx4 module.

Sources and accuracy

The decoding rules are based on the manufacturers’ published part-numbering documentation: Samsung’s DDR4 product guide and DDR5 module datasheets, SK hynix’s DDR4 and DDR5 module part-number decoders, Micron’s module part numbering guides and Kingston’s memory part number decoder. They were then checked against real modules from our buying catalog.

Manufacturers add codes over time. When the decoder meets a code it does not know, it says so instead of guessing. If it gets a part number wrong, email harlan@ocitech.com and we will fix it.

Questions

Decoding RAM part numbers: common questions.

Where is the part number on a RAM module?

On the white label on the module. It is the longest code on the label and starts with M for Samsung, HM for SK hynix, MT for Micron or K for Kingston. The shorter line with the capacity, rank and a PC4 or PC5 code is the specification line, which the decoder also accepts.

Why is the rank marked “worked out”?

Samsung, SK hynix and Micron DDR4 part numbers do not include the rank. The decoder calculates it from the capacity, the DRAM die density and the DRAM width, all of which are in the part number. The result matched the label on the modules we tested, but if the two ever disagree, trust the label.

Can it decode HPE, Dell or Lenovo part numbers?

No. Server-brand spare and option numbers do not follow a scheme that can be decoded. The same label almost always carries the DRAM manufacturer’s own part number as well, and that one decodes. If you only have the server-brand number, send it to us and we will cross-reference it.

What do the extra letters after the speed code mean?

They are customer, production or component-sourcing codes, such as the register and power-management chip combination on a DDR5 module. They do not change the capacity, speed, type or rank, so two modules that differ only in that suffix have the same specification.

Does it work for desktop and laptop memory?

Yes, for modules made by these four manufacturers. Unbuffered DIMMs and SODIMMs use the same numbering schemes as server modules, with a different module type code.
