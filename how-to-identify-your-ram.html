How to identify your server RAM.

Why identifying your memory matters

Two sticks of RAM that look identical can be worth very different amounts. A 64GB DDR4 LRDIMM and a 64GB DDR4 RDIMM are built differently, sell into different systems, and carry different prices on the used market. Before you request a quote — or decide whether a pile of pulled modules is worth shipping — it pays to know exactly what you're holding. The good news: everything you need is printed on the module itself.

Step 1 — Know the three server DIMM types

Almost all enterprise memory falls into one of three types. The difference is how the module buffers the signals between the DRAM chips and the CPU's memory controller.

UDIMM — Unbuffered

No buffering between the chips and the controller. This is standard desktop and workstation memory, plus some entry-level servers. It comes in ECC and non-ECC versions. UDIMMs are generally the lowest capacity per module and, in the used server market, usually the lowest value of the three.

RDIMM — Registered

Adds a register that buffers the address and command signals, which lets a server run more modules per channel with stability. This is the workhorse of mainstream rack servers (think Dell PowerEdge, HPE ProLiant, Cisco UCS). RDIMMs are ECC by default and are the most common thing we buy.

LRDIMM — Load-Reduced

Buffers all the signals — address, command, and data — through an on-module buffer, which reduces electrical load and allows the highest capacities per module (128GB, 256GB and up). LRDIMMs live in high-memory servers and often carry the strongest per-module prices.

Quick tell: if a module was pulled from a rack server and the label says ECC with a "R" or "L" in the type, it's an RDIMM or LRDIMM — the parts most worth pricing. Desktop-style UDIMMs are the exception in a server context, not the rule. There's also SODIMM, the small form factor used in laptops and compact systems — physically shorter, and identified the same way by its label.

Step 2 — Read the module label

Most modules carry a sticker with everything you need. Here's what each field tells you:

Capacitye.g. 16GB, 32GB, 64GB, 128GB — the size of that single module
Speed codePC3 = DDR3, PC4 = DDR4, PC5 = DDR5 (e.g. PC4-25600 = DDR4-3200; PC5-38400 = DDR5-4800)
Rank & width1Rx8, 2Rx4, etc. — number of ranks and the width of each DRAM chip
TypeR = Registered (RDIMM), L / LR = Load-Reduced (LRDIMM), E = ECC Unbuffered, U = Unbuffered
Part numberThe single most useful field — it encodes all of the above

Step 3 — Decode the part number by brand

If you can read one field, make it the part number. The three DRAM makers each use recognizable prefixes, so even the first few characters tell you the generation and type at a glance.

Samsung (starts with M)

M393…DDR4 RDIMM
M386…DDR4 LRDIMM
M321…DDR5 RDIMM

SK Hynix (starts with HMA / HMC)

HMA…DDR4 family (RDIMM/LRDIMM per the suffix)
HMCG…DDR5 family

Micron (starts with MTA / MTC)

MTA…DDR4 family
MTC…DDR5 family

OEM-branded modules (HPE, Dell, Cisco, Lenovo) carry their own part numbers on the sticker, but the DRAM inside is still made by one of these three. If you have the OEM number, that works too — we cross-reference it.

Step 4 — Tell the generations apart

If the label is missing or unreadable, a few physical and code tells separate the generations:

  • DDR3 — older platforms; PC3 speed code; lowest value today.
  • DDR4 — the current bulk of the used market; PC4 speed code; notch position differs from DDR3.
  • DDR5 — newest; PC5 speed code; an on-module power management IC (PMIC) is visible, and the notch position differs again. Strongest pricing right now.

Questions

Identifying your RAM — common questions.

How do I tell an RDIMM from a UDIMM?

The fastest way is the part number and the printed label. Registered (RDIMM) and load-reduced (LRDIMM) modules are labeled as such and use buffered part-number families; unbuffered desktop/workstation memory (UDIMM) is not. If you only have the module in hand, RDIMM/LRDIMM are almost always ECC server parts pulled from rack servers, while UDIMMs come from desktops and workstations.

What does 2Rx4 or 1Rx8 mean on the label?

It describes the module's rank and DRAM width. 1R/2R/4R/8R is the number of ranks (1 = single-rank, 2 = dual-rank, and so on). The x4 or x8 is the width of each DRAM chip. It affects capacity and, in the used market, value — so it's worth reading it off the label when you request a quote.

Does the brand printed on the label change what the RAM is worth?

Somewhat. The underlying DRAM maker — Samsung, SK Hynix, or Micron — and the exact part number matter more than an OEM sticker (HPE, Dell, Cisco, Lenovo). Send the part number and we price it on the actual module, not the badge.
